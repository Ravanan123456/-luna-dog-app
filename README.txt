# Luna — My Dog

An English-language dog care and training tracker for Jishnu's 6-month-old Belgian Malinois, Luna.

## Features
- Training checklist
- Daily care checklist
- Custom care reminders
- Health and vaccination record notes
- Editable dog profile
- Local browser storage and JSON backup export

## Run on Android
For the best installable-app experience, host this folder on an HTTPS static host (for example, GitHub Pages), then open the site in Chrome and choose **Add to Home screen** / **Install app**.

You can also open `index.html` locally to try the basic app, though offline installation and service-worker caching require HTTPS or localhost.

All data is stored in the browser on the device. Export a backup before clearing browser data.
